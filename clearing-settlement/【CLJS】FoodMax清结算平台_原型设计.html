分账明细

业务流水 · 功能说明

功能定位

分账明细是清结算平台「分账（订单级两方 + 物流独立）」的事实源。履约完成的订单从订单中心（OMS）接入、通过数据预检（订单头 = 商品行 + 运费 + BCRS）后，按子订单（商家维度）按订单级两方拆分——订单实付 = 应付店铺 + 平台抽佣(含税) − 平台补贴（应付店铺 = 订单实付 − 抽佣 + 补贴，运费/BCRS 透传店铺）；物流应付为平台 ↔ 物流平台的独立结算项，不进订单实付拆分。本页列示 订单信息（订单实付/运费/BCRS）+ 商家分账（平台抽佣含税/平台补贴/应付店铺）+ 仓配分账（物流抽佣/物流补贴/物流应付）+ 平台收入（= 平台抽佣(含税) − 平台补贴，净收入；物流应付为独立结算项不进平台收入）；商品行级明细在抽屉展开。

  • 恒等式（订单级两方）：订单实付 = 应付店铺 + 平台抽佣(含税) − 平台补贴（严格相等，差额 = 0.00）。
  • 应付店铺 = 订单实付 − 平台抽佣(含税) + 平台补贴（运费/BCRS 透传店铺）；物流应付 = 物流抽佣 − 物流补贴（独立仓配/履约服务费、不含运费、平台↔物流独立结算项）；平台抽佣(含税) = 计佣基数(商品含税) × 费率（抽佣本身即含 GST，不再 ×1.09）。
  • 行级（商品行）vs 订单级：行级不含运费/BCRS；订单级应付店铺 = Σ行级 + 运费透传 + BCRS 透传。运费/BCRS/GST 透传给店铺；物流应付独立、不进订单实付拆分。
  • 正向订单两方为正；逆向（退款）订单取负（红字），与正向同口径反向。

功能定位

清算支付 = 清分支付单的跨结算单台账。结算单进入「待付款」后，系统按每张结算单自动拆成 3 张清分支付单——店铺结算清分 / 仓配清分 / 平台清分——各带收款主体、收款账户、金额，独立跟踪清分状态与支付状态。替代旧流程「一张结算单人工分头转 3 笔、进度不可视」。

分账台账

功能定位

分账台账是把分账明细（子订单粒度的分账事实）透传聚合而成的一张只读台账，本身不产生任何数据、不产生任何分录，只是「分账明细 + 结算单状态 + 清算支付状态」的聚合镜像，供运营 / 财务做查询、监控、对账。归属：结算管理组。

三视角 Tab，每个主体的金额按结算状态两级拆分：已分账 = 未结算 + 已结算；已结算 = 已付款 + 未付款。

三视角

  • 平台视角：平台抽佣(含税) = 计佣基数(商品含税) × 费率（抽佣本身即含 GST 9%，不再 ×1.09）；单主体（10X AI Tech），无独立合计行。

  • 仓配视角：物流应付 = 物流抽佣 − 物流补贴（独立仓配费、不含运费），按仓配服务商一行 + 合计行。

开票管理

结算管理 · 功能说明

功能定位

基于结算单，平台（10X AI Technology Pte. Ltd.）就每张结算单的平台抽佣(含税)部分，向店铺开具一张正向佣金税票（TAX INVOICE）。一结算单一发票（结算单号 × 店铺）。价税合计 = 平台抽佣(含税)；佣金不含税 = 价税合计 ÷ 1.09；GST = 价税合计 − 佣金不含税（抽佣本身即含 GST 9%，不再另加）。金额全部为 S$。

只有正向发票，无红冲 / 贷记单（Credit Note）/ 逆向。结算单内若发生退款，佣金基数已由结算引擎在净额轧账阶段扣减，开票取结算单最终确认的抽佣终值，天然是正向单张终值。

佣金收入唯一在开票确认时确认：借「其他应付款—平台抽佣」/ 贷「主营业务收入—佣金」+「应交税费—GST」。结算 / 清分环节不重复入账。

关键规则

  • BR-01 唯一键：仓配商编码 wd_code 全平台唯一，作为分账/清分/台账仓配侧外键主键；`WD`+顺序号，≤32 位。
  • BR-02 有且仅一个主收款账户；账号非空 + SWIFT 8/11 位字母数字方可置"生效"，否则"待校验"。币种默认 S$（SGD）。
  • BR-05 账户状态 = 失效/待校验时，禁止被仓配清分引用为收款账户——清算支付发起打款时拦截并告警。
  • BR-03 已产生分账/清分记录的仓配商不可删除、仅可停用（二次确认）。停用后在途物流应付继续走完，停用仅阻止次日起新引用。
  • BR-06 金额口径不在本模块：物流应付 = 物流抽佣 − 物流补贴（独立仓配费、不含运费），由分账明细产出（口径基线 §2）；本模块只提供收款主体与账户，不产生分录。
  • BR-07 名称/类型/覆盖区域/费规则文本变更均写操作日志（时间/字段/原值→新值/操作人/来源）。
  • 下游衔接：wd_code 是清算支付（仓配清分收款账户）、分账台账（仓配视角聚合）、分账明细（物流应付归属 BU）的归集外键。分账出现无匹配 wd_code → 物流应付挂"仓配主体缺失"，告警运营补建档案后重跑归集。
