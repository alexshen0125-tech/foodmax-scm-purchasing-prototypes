功能点说明 — 商货品分类商品段映射（海外）

为什么做这个

  • 海外商品 / 货品分类量大、命名英文化（数千条），手动逐条挂商品段不可行；本页用 AI 自动赋值减轻业务工作量
  • 分类档案由上游业务系统单向同步，FMS 不再重复维护，避免双口径
  • 仅向海外财务、海外运营、超管开放；国内角色不展示菜单
  • 按 SITE × 类型（商品 / 货品）维护映射；同一 SITE 下商品分类、货品分类是两套独立档案
  • 商品段数据打通现有商品段接口，本页只引用、不维护；人工可绑全量生效段，AI 自动赋值仅在 5 个优先段内尝试：29 水产 / 20 水果 / 19 肉禽蛋 / 12 蔬菜 / 11 标品，其余段需人工选

页面结构

  • 筛选区：SITE（默认"全部 SITE"，进入页即看到所有有权 SITE 数据） / 分类类型（商品 / 货品） / 分类名称 / 编码 / 分类级次（1–5） / 上级分类 / 是否末级 / 绑定状态（已绑 / 未绑 / 无需绑定）
  • 列表列：多选 / SITE / 分类名称+编码 / 分类级次 / 分类类型 / 1–5 级分类链路 / 是否末级 / 已绑商品段（含来源标记） / 状态 / 操作（仅"日志"）
  • 分类层级：支持 1–5 级，分类自身级次 = N 时，1～N 级列填祖先链 + 自身，N+1～5 级列填 "—"
  • 本页不支持手动新增 / 编辑 / 删除分类；分类源数据归上游

核心交互

  • AI 自动赋值（仅首次 + 仅末级）：上游同步进来一条末级分类时，系统异步调 AI 基于「1–4 级分类名称 + 编码 + SITE + 类型」综合语义判断，命中优先池后自动绑定，单元格标记 AI
  • 非末级分类（自身仍有下级）：商品段列显示 "—"，状态 = 无需绑定，多选框置灰，不参与统计
  • 上游后续变更不重赋值：分类信息被上游修改（改名 / 改编码 / 改层级 / 改上级），商品段绑定保持不变；唯一例外是末级↔非末级互转（见异常态）
  • 绑定/变更商品段（批量）：列表勾选 ≥ 1 条末级 → 点顶部「绑定/变更商品段」→ 选段确认；支持跨 SITE / 跨类型混合勾选，逐条落库；未勾选时点击会拦截提示
  • 来源标记：单元格只显示最后一次写入来源——AI 或 手动；未绑定且 AI 未命中时显示 AI 未识别。日志保留完整变更轨迹
  • 行操作只剩"日志"：编辑 / 删除 / 解绑由"上游维护 + 批量变更"覆盖

每周告警

  • 每周一 09:00（Asia/Singapore）扫描全量末级未绑分类总数 N
  • N > 0 时向飞书群 oc_48f43beee86de75552e2d9d4e8dd9c04 推文本：「【FMS · 商货品分类商品段映射】当前有 N 条末级商货品分类未绑定商品段，请及时处理：<页面链接>」；N = 0 不发
  • 飞书接口失败 → 重试 3 次仍失败 → 错误日志 + 邮件告警财务 IT，不阻塞业务

异常态

  • AI 失败 / 超时 → 商品段留空 + 标记「AI 未识别」，不阻断上游同步，等人工补绑
  • 商品段在独立档案侧被废弃 → 本页不展示废弃标记；批量变更弹窗下拉自动过滤掉
  • 上游推送字段缺失（如缺级次） → 入库失败 + 异常队列，不调 AI，告警财务 IT
  • 末级 → 非末级（新增了子分类） → 原绑定自动解除，状态变「无需绑定」，写日志
  • 非末级 → 末级（删除了所有子分类） → 该分类首次成为末级，触发一次 AI 赋值
  • 财务核算时分类未绑 → 财务模块兜底归"未分类"科目

关键业务规则

  • BR-01～04：分类按 SITE 隔离；商品 / 货品独立；分类源数据由上游推送，本页不维护；推送字段含 SITE / 类型 / 名称 / 编码 / 级次 / 上级编码
  • BR-05：商品段只引用、不维护；下拉展示全部生效段，人工可绑任一段
  • BR-06：一条分类映射一个商品段
  • BR-07：商品段废弃在独立档案侧处理，本页不展示废弃态
  • BR-08：仅末级参与绑定；非末级 = 无需绑定，不可勾选，不计入未绑统计
  • BR-09：批量变更需勾选 ≥ 1 条末级；支持跨 SITE / 跨类型混合
  • BR-10：AI 仅在末级首次同步时触发；输入 = 全部祖先链 + 自身（≤ 5 级）+ SITE + 类型
  • BR-10.2：AI 仅在 5 个优先段内匹配（29 / 20 / 19 / 12 / 11），多命中按编码顺序取首个
  • BR-10.3：未命中优先池 → 留空 + 标「AI 未识别」
  • BR-11：上游后续修改分类信息不重赋值；末级↔非末级互转时按 11.1 / 11.2 例外处理
  • BR-14：单元格展示"最后一次写入来源"（AI / 手动）；日志保留完整轨迹
  • BR-A1～A4：每周一 09:00 SGT 飞书群告警未绑数
