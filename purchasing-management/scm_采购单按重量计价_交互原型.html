改造说明
字段改动类型必填默认值规则
计价方式新增 采购明细列枚举：按数量 / 按重量是（仅标品）同供应商 + 同货品上一张采购单的计价方式；无历史 = 按数量仅标品（saleWay=0）显示切换；非标品固定显示「按重量」不可改；包装物、押金行显示 "--"。草稿/待下单/待发货可改，其余状态只读
采购单价(含税/未税)改造 输入单位随计价方式变数值，4 位小数是按数量：带出现有报价 /件；按重量：空按数量 = 现状（/件 + /箱 两个输入框）；按重量 = 只有一个输入框 /kg，隐藏 /箱 输入框。另一个税态（未税/含税）列同步显示 /kg
折合件单价(含税/未税)新增 采购明细列（只读）数值，4 位小数—自动算= 采购金额 ÷ 采购数量；仅按重量行有值，按数量行显示 "--"
采购重量新增 采购明细列数值，3 位小数，单位 kg按重量时必填采购数量 × 单件净含量（货品资料净含量单位为 kg/g 时自动算，g÷1000）>0；手动改过后，再改采购数量不再自动覆盖重量；货品未维护重量类净含量时为空，提示手填。按数量 行显示 "--"
采购数量不变—是—按重量 行仍必填件数（入库按件收货、库存按件记）
采购金额(含税/未税)改造 计算公式数值—自动算按数量：单价 × 采购数量（现状）；按重量：单价/kg × 采购重量。按重量 时金额框只读（改金额会反算单价，与重量口径冲突）

计算示例（三文鱼整条，按重量，含税）

  1. 录入：采购数量 40 条，单件净含量 6 kg → 采购重量默认 240.000 kg；供应商实际报 236.5 kg，手改为 236.500
  2. 单价 9.80 /kg → 采购金额 = 9.80 × 236.5 = 2,317.70 USD
  3. 折合件单价 = 2,317.70 ÷ 40 = 57.9425 /条（落库为现有 price 字段，下游库存成本/结算/开票沿用件单价，不改）

业务规则

  1. 切换计价方式金额不变：按数量→按重量，单价/kg = 原件单价 ÷ 单件净含量，重量 = 数量 × 单件净含量；无净含量时单价、重量清空待填。按重量→按数量，件单价 = 原金额 ÷ 采购数量。
  2. 落库：明细新增 计价方式、重量单价（含税/未税）、采购重量 3 个字段；现有 price / excludingTaxPrice 存折合件单价（4 位小数），purchaseAmount 存 重量单价 × 重量，保证下游只读件单价的环节不受影响。
  3. 保存校验：按重量 行 采购数量、采购重量、单价/kg 三者缺一拦截，提示「第 N 行：按重量计价需填写采购重量」。
  4. 编辑态：计价方式、采购重量跟随现有 isFullEditableStatus（草稿/待下单/待发货）；待入库及之后只读。
  5. 详情页：采购单价显示「9.80/kg USD」；新增 计价方式、折合件单价(含税/未税)、采购重量 列，一字段一列。

交互自检（7 项）

  1. ☑ 操作路径 ≤ 线下：线下 = 供应商报"每公斤多少、共多少公斤"；线上 = 切「按重量」→ 填单价/kg →（重量已预填）核对重量，与线下一致
  2. ☑ 输入方向 = 思维方向：供应商报的是 /kg 单价和总重量，就让采购录 /kg 和 kg，不让他自己折成件单价
  3. ☑ 可预填已预填：重量 = 数量 × 货品净含量预填；计价方式带上一单
  4. ☑ 无需心算：金额、折合件单价、另一税态单价全部自动算
  5. ☑ 高频有默认：计价方式默认带同供应商同货品上一单，首次 = 按数量（现状）
  6. ☑ 关联字段联动：改数量 → 重量跟随（未手动改过时）→ 金额 → 折合件单价；切换计价方式金额不变
  7. ☑ 核心操作 ≤ 3 步：切换计价方式（1）→ 填单价/kg（2）→ 核对/修改重量（3）

待确认

  1. 待确认 结算按订货重量还是实收重量：本原型假设 按订货重量锁定金额，入库按件收货，结算 = 实收件数 × 折合件单价。若要按仓库实称重量结算，需改 WMS 收货录重量 + 结算取数，范围大很多。
  2. 待确认 重量单位是否固定 kg（本原型假设固定 kg，与非标品一致）。
  3. 待确认 导入/导出采购商品模板、VMS 供应商端采购单详情、采购单打印是否同期加 计价方式/采购重量（本原型未画）。
