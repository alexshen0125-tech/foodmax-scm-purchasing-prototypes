业务规则与验收标准（第一阶段）
最小可用范围内的全部 BR 与 AC。BR 用于研发实现，AC 用于测试验证（Given/When/Then）。容器类型/容量/关联押金 SKU 等扩展项留待二期。
货品主数据 — 业务规则
BR-01
新增字段范围：本期货品主数据 BCRS 部分仅新增 2 个字段 —「是否支持 BCRS」(bcrsEnabled, boolean, 默认 false) 与「押金单价」(depositPrice, decimal, S$)
BR-02
押金计算依赖现有箱规：押金行数量 = 主商品采购数量 × 货品主数据 boxSize（箱规字段为现有字段，非本期新增）
BR-03
押金单价校验：当 bcrsEnabled = true 时，depositPrice 为必填且必须 > 0；为 false 时该字段隐藏并清空
BR-04
站点开关：仅 stationInfo.countryCode === 'SGP' 时显示 BCRS 字段与押金行；其他站点完全隐藏
采购单 — 业务规则
BR-05
押金独立行：采购支持 BCRS 的商品时，系统在该商品行下方追加独立押金行（不增加价格列）；押金行商品名固定为「BCRS 押金」
BR-06
押金数量公式：押金行数量 = 主商品采购数量(箱) × 主商品 boxSize；单位「个」
BR-07
押金单价不可编辑：押金行单价直接取主商品货品主数据 depositPrice，PO 中 disabled
BR-08
数量联动：主商品数量变更（含 PO 编辑、退回修改）→ 押金行数量与金额自动刷新
BR-09
级联删除：删除主商品行 → 自动删除关联押金行；用户不能单独删除押金行
BR-10
财务挂账分离：押金金额不进存货成本，单独挂「应付押金」往来科目；底部汇总区独立列示 BCRS 押金合计
退供单 — 业务规则
BR-11
退货押金行：退供 BCRS 商品时，系统在该退货行下方追加「BCRS 押金」返还独立行；退货金额按系统口径正数显示（filterAmount）
BR-12
退货押金数量公式：押金返还数量 = 退货数量(箱) × 主商品 boxSize；单位「个」
BR-13
退货数量联动：退货数量变更 → 押金返还行数量与金额实时同步
BR-14
退货数量校验：退货数量 ≤ 关联 PO 的原采购数量；超出时阻断提交并提示
BR-15
财务冲销：押金返还金额冲销原 PO 的「应付押金」往来科目，不影响存货成本
BR-16
退供单押金不可单独删除：押金返还行随主商品退货行级联存在，用户不能单独删除
结算单 / 上传发票 — 业务规则
BR-17
BCRS 判定（结算侧）：结算单关联的采购单只要有一个商品含 BCRS 标识，即判定该结算单含 BCRS；上传发票页与结算单详情页均展示「押金金额」字段
BR-18
发票金额含押金：应开票金额 = 商品总额(含税) + 押金金额；上传发票时发票含税金额须 ≥ 应开票金额，否则提示金额不足
BR-19
结算金额含押金：押金金额计入采购单据总额 → 计入结算金额总计与应付金额总计（底层复用系统 purchaseOrderPackageTotalAmount 字段）
BR-20
无 BCRS 时隐藏：关联 PO 无任何 BCRS 商品时，「押金金额」「押金应开收据总金额」为 0，可隐藏 BCRS 相关字段
BR-21
押金不计 GST：BCRS 押金部分含税额 = 未税额（税额 0），发票税额仅按商品金额计算
VMS 供应商端 — 业务规则
BR-22
VMS 采购单展示：供应商端采购单详情（purchase-detail.vue）中，BCRS 押金作为「押金」类型独立行展示（商品类型列=押金）；订单金额(含税/未税)包含押金
BR-23
VMS 退货单展示：供应商端退货单详情（refund-detail.vue）中，BCRS 押金返还作为「押金」类型独立行展示（退货类型列=押金）；退货金额(含税/未税)包含押金返还
BR-24
SCM/VMS 数据一致：同一采购单/退货单在 SCM（采购员端）与 VMS（供应商端）展示的 BCRS 押金行、数量、金额必须一致（同源数据）
