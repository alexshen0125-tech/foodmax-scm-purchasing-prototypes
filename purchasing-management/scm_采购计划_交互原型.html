原料货品采购计划预测流程
5 大计算块的输入输出 + 中间计算 + 最终总采购量 + 按日采购计划公式。点击采购计划页的行可看该 SKU 的具体取数。
5 大计算块（输入逻辑）

预测覆盖天数逻辑

  • 基础备货天数（销售分层 × 保质期矩阵）
  • VLT/VCT 修正天数
  • 缺货系数：保质期 ≥3 天 +2；<3 天 +1.5
  • 周末 / 节假日系数
输出：最终备货天数

天级平均日销逻辑

  • (近 7 日日均销 + 近 3 日日均销) / 2
  • 售罄日不计入分母与分子
  • SKU 销量 → 成品 item 销量 → BOM → 原料 item 销量
输出：μ_demand（原料级日均销）

当日预估剩余销量逻辑

  • SKU 实时销量 → 成品 → BOM → 原料 item 实时销量
  • P_now = 当日实际销量 / 当日大盘预估销量
  • P_now ≤ 当日平均进度+20% → 剩余=大盘预估−当日实际
  • 否 → 剩余=近 7 日单日最大销量−当日实际
输出：当日预估剩余销量

今日在途库存逻辑

  • 状态：待下单 / 待发货 / 待入库 / 入库中
  • 按预计到货日分桶
输出：今日在途 / 明日在途 / 后日在途 / … / T 日在途

库存逻辑

  • 仓库销售可用库存（WMS available_qty）
输出：T 日销售可用库存
▼

备货目标

覆盖天数 × 预测销量 ÷ (1 − 安全库存比例 SS%)

T 期末库存

T 日在途库存 + T 日销售可用库存 − T 日预估剩余销量
▼

总采购量

总采购量 = 备货目标 − T 期末库存
▼

T 日采购计划

= T+1 备货目标 − T 日期末库存 − T+1 在途库存

T+1 日采购计划

= T+2 备货目标 − T+1 日期末库存 − T+2 在途库存

T+N 日采购计划

= T+【N+1】备货目标 − T+N 日期末库存 − T+【N+1】在途库存
